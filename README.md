# Robot Arena — Combat de robots

Prototype web 3D construit avec Three.js.

## Modes de jeu
- **Combat** : duel en arène fermée, dégâts et élimination.
- **Sumo** : dohyo circulaire, pousser l'adversaire hors du cercle, deux manches gagnantes.
- **Hockey** : patinoire, palet et cages, premier à trois buts.

## Lancer
Le jeu est statique : ouvrir `index.html` via un serveur HTTP ou publier le dépôt avec GitHub Pages. Three.js est chargé depuis jsDelivr.

## Commandes
- ZQSD / WASD ou flèches : piloter.
- Espace : boost.
- E : attaquer en combat ou frapper le palet en hockey.

Les règles sont des adaptations ludiques inspirées de compétitions de robots réelles, et non des reproductions intégrales de leurs règlements.
